# Frontend Design Plugin

Create distinctive, production-grade frontend interfaces with high design quality.

## Overview

This plugin provides a skill that guides Claude to create visually striking, memorable frontend interfaces that avoid generic "AI slop" aesthetics. It emphasizes bold creative choices, distinctive typography, cohesive color themes, and intentional design decisions.

## Usage

Use this skill when asking Claude to build:
- Web components
- Landing pages
- Full applications
- UI interfaces

The skill encourages Claude to:
1. Understand the context and purpose
2. Commit to a bold aesthetic direction
3. Implement production-grade, functional code
4. Focus on distinctive typography, colors, motion, and spatial composition

## Installation

This plugin is included in the repository and will be automatically available when using Claude Code with this project.

## Design Philosophy

- **Bold over safe**: Choose distinctive aesthetics over generic patterns
- **Intentionality over intensity**: Both maximalism and minimalism work when executed with precision
- **Context-specific**: Every design should feel genuinely crafted for its purpose
- **Production-grade**: Real, working code with exceptional attention to detail
